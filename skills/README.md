# Project Skills

本项目自己的可复用技能，不属于 `light_skills/` 里的书稿。

- [`source-to-book`](./source-to-book/SKILL.md)：把一个或多个开源项目、文档集或课程材料整理成结构化学习书的完整流程，包含来源固定、快照、双语/中文页、批次翻译、结构校验、静态 HTML 和发布门禁。
  - [`references/batch-prompt.md`](./source-to-book/references/batch-prompt.md)：可直接复用的批次翻译子代理提示。

这些技能服务于 `light_skills/` 这本书，也可以复制到其他知识型书籍项目中使用。
