# 分诊标签

这些技能用五个标准分诊角色来表达状态。本文件把这些角色映射到本仓库议题跟踪器里实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们的跟踪器中的标签 | 含义 |
| -------------------------- | -------------------- | ---- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估这个 issue |
| `needs-info`               | `needs-info`         | 等待报告者补充信息 |
| `ready-for-agent`          | `ready-for-agent`    | 规格已完整，可交给 AFK agent |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现 |
| `wontfix`                  | `wontfix`            | 不予处理 |

当某个技能提到某个角色时（例如“打上 AFK-ready 分诊标签”），使用本表中对应的标签字符串。

把“我们的跟踪器中的标签”这一列改成你实际在用的词汇。
