# 阶段边界

**阶段（phase）** 是会话里的一块工作：追问、实现、QA。这个定义故意做得模糊：当你想“好，这块做完了”的时候，一个阶段就结束了。

**阶段边界**是两个阶段之间的空隙，也是这个决策唯一该出现的地方。阶段中途没有决策可做：要么继续，要么把剩下的工作拆给子代理。在阶段中途压缩会让 agent 丢掉线索。

## 五个选项

| 选项         | 它做什么                                                       |
| ------------ | --------------------------------------------------------------- |
| **继续**     | 留在会话里。完全不做上下文切换。                                 |
| **`/clear`** | 清空上下文窗口，从零开始。                                       |
| **`/handoff`** | 写一个可移植的 markdown 文件，在任何地方用它给会话做种子。      |
| **子代理**   | 把任务送到它自己的上下文窗口，拿回一份报告。                     |
| **`/compact`** | 压缩这份上下文，用摘要给一个新会话做种子。                     |

## 决策树

在边界上从上往下走。第一个**是**获胜。

**1. 你能在这个会话里继续吗？** 两件事会让答案变成“是”：下一个阶段需要把这个阶段当作**一手来源**，或者你还剩足够的[智能区](https://www.aihero.dev/ai-coding-dictionary/smart-zone)（约 150k tokens）让下一个阶段装得下。追问 → 实现是典型的“是”：实现想要的是原样的推理过程，而不是它的摘要。继续不花成本、不丢东西，所以先把它排除掉，再谈别的。

**2. 这份上下文对接下来无关吗？** 这个会话里的一切（探索、决策、死胡同）都是可丢弃的吗？如果是，就 **`/clear`**。它是棋盘上最便宜的一步：不花时间，把整个窗口还给你。`/clear` 也不是终点：旧会话仍然可以恢复。

把这件事做错的代价是单向的。清掉一份*相关*的上下文，你就失去了所建之物背后的**为什么**，之后无论怎么回读 diff 都换不回来。

**3. 你需要交接吗？** `/handoff` 的范围很窄。只有当你正在：

- 切到**新的运行框架**（Claude → Codex），
- 搬到**新的目录**或仓库，
- 把工作交给**同事**，
- 或者分叉一个你在**阶段中途**发现的旁支任务、又不打乱手头的事，

才需要它。这份清单就是全部条款。`/handoff` 换来的是**可移植性**：一个能旅行的文件。如果没有东西在旅行，你就不需要它。

**4. 这个任务能在你不在的情况下完成吗？** 它的范围收得够紧，可以让你离开键盘、不用指挥地跑完吗？那就把它交给**子代理**，这个会话原封不动。自动审查是典型场景：agent 读 diff 并汇报，它做这件事的时候不需要你在场。

**5. 否则，`/compact`。** 相关的上下文、同一个运行框架、同一个目录，而你需要留在回路里：这就是决策树落下的位置，而且它经常落在这里。给它一条指令（`/compact we're going to QA this area`），让摘要保留下一个阶段需要的东西。

`/compact` 是**默认选项，而不是第一个伸手去拿的**。它坐在底部，是因为它上面的四个问题都更便宜或更精确。人们一上来就用它时，失败模式是一个新会话对某个被摘要压平的决策自信地做错。

## 一手来源与二手来源

除了**继续**，每一步都把**一手来源**变成**二手来源**：真实发生过的会话，被它的摘要取代。这笔交换的形状总是一样的：

| 来源                              | 信息 | 噪音 | 腾挪空间 |
| --------------------------------- | ----------- | ----- | ------------ |
| 一手（继续）                      | 完整        | 多    | 少           |
| 二手（`/compact`、`/handoff`）    | 有损        | 少    | 多           |

这就是为什么第 1 个问题排在最前面。只有当留下的代价高于它省下的东西时，你才付这笔有损的账。

## 这些是判断题

这些问题不是客观的：每一个里面都有品味，同一个边界在不同日子可以走向两边。价值在于**按顺序**问它们，并且在边界上问，而不是在工作做到一半时问。
