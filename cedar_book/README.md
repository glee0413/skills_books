# Cedar 授权策略实战

从 Cedar 的策略语言、Schema、Rust SDK 和 CLI 出发，结合 TinyTodo 与六个真实用例，系统掌握如何把授权逻辑从业务代码中拆出来。

## 这本书怎么读

- 想先建立直觉：读“导读”“基础模型”和“策略语言”。
- 想马上跑起来：读“CLI 快速上手”和“TinyTodo 教程”。
- 想在 Rust 项目里集成：读“Rust SDK”和“Schema 与验证”。
- 想看真实业务怎么建模：读“六个真实用例”。

## 目录

- `book/`：主题章节。
- `catalog/`：Cedar 文档、Rust SDK、示例仓库的中文精读条目。
- `source-snapshots/`：固定 commit 的英文原文，只读。
- `site/`：生成的静态 HTML。
- `sources.json`：来源、版本、哈希和状态。
- `book.json`：章节与目录。
- `GLOSSARY.md`：术语表。
- `NOTICE.md`：许可证与归属。
